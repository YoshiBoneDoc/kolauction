# Wall of Shame artwork

`wall-of-shame-watercolor.png` was generated using the built-in imagegen tool.
It is a decorative anonymous fantasy adventurer, not a depiction of a real player.

Prompt: square watercolor bust portrait of an anonymous, faceless stick-figure
fantasy adventurer; thin black sketch lines, round blank face, floppy dark hat,
slumped shoulders, muted sepia/sage/dusty-blue washes, warm cold-press paper,
irregular pigment pooling and unpainted margins. Centered head and shoulders,
no text, numbers, border, frame or watermark. The website supplies wooden frames.
